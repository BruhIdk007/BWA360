# Licensing Status

The BWA360/LexEngine project-wide source license has **not yet been selected** in this repository snapshot.

Before the repository becomes open to outside code contributions, select and add an explicit project license.

## Third-party-derived changes

The M1 work modifies/patches SynthXEX behavior. SynthXEX identifies itself as GNU Affero General Public License version 3 or later. Any distribution of modified SynthXEX source/binaries must continue to satisfy its upstream license terms.

Keep third-party patches isolated under `patches/` or reproducible transformation scripts under `tools/` and preserve upstream copyright/license notices.

## Proprietary game content

A software license for BWA360 does not grant rights to redistribute Bookworm Adventures assets or executables. Original game material must remain outside this repository.

This document is project organization guidance, not legal advice.
